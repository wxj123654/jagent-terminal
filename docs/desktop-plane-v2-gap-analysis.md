# 桌面 V2 原型与当前实现差异清单

## 范围与证据

- 用户指定对照基准：`design/desktop-plane-v2.html`，说明：`design/desktop-plane-v2.md`。
- 对比对象：本轮当前磁盘源码，包含未提交修改；不是只对比 HEAD。
- 本轮只分析，未修改应用源码。两名子代理分别做布局/视觉与功能流程独立核查；主代理复核核心路径并生成原型/原生测试渲染截图。
- 原型浏览器桥未连接，改用已安装 Playwright + Chrome headless；原生使用 GPUIX TestRenderer。截图窗口均为 1280×800、输出 2560×1600。不是用户正在运行的真实 PTY 窗口截图。
- 截图：`/tmp/v2-prototype-default.png`、`/tmp/v2-prototype-empty.png`、`/tmp/v2-native-default.png`、`/tmp/v2-native-workspace.png`。后两个分别为无活动路由默认页、空工作区页；勿混淆为空态缺失。
- 原生默认截图脚本输出 done 后未自行退出，被超时结束；图片已成功生成并读取。另一次工具弹窗截图尝试调用了不存在的 dialogKeyboard.openToolMenu，失败；不将工具弹窗列为本轮截图验证通过。
- detector 对 `packages/app/src/plane` 返回 `[]`，但不理解 GPUIX 真实布局、焦点与 PTY；不代表专项审计通过。未重跑项目完整测试。
- V2 文档仍声明待评审、不替代旧实现契约。这里的 P1/P2 是“对齐 V2 的执行优先级”。既有 Git 图、Chat/ACP 是否改入口/移除，需要显式迁移决定，不可借视觉修复直接删除已有能力。

## 总结

当前是“旧版 One Dark 工作台 + 部分 V2 侧栏结构”，不是完成的 V2。双区、28px 行、10px 圆角、时间分组已接入；整体配色、左右布局、工具栏、工作面板、通知、空态仍有明显差距。部分注释写着 V2，但实际消费的 token/组件仍为旧版。

## P1：结构和主流程

### D01 整体色板仍是 One Dark
- 当前：`packages/app/src/ui/tokens.ts:10` 起：sidebar/titlebar `#21252b`、pane `#1e2127`、terminal `#1a1d23`、accent `#61afef`、muted `#5c6370`。
- 原型 `:root`：主区 `#181818`、终端 `#0d0d0d`、侧栏黑底叠白色 4.5%→2% 微渐变；白色 accent；白色 70%/52%/56% 的文字层级；tile/hover/active 为白色 3.5%/6%/10%。
- 修改：建立明确的 V2 语义色，不只修改 Sidebar 注释。通用 hover/selected、输入框、浮层、按钮和状态点联动核查。侧栏 gradient 若无原生原语可在工程内近似，不能继续用蓝灰底冒充。
- 注意：终端 ANSI 调色盘、Git lane 语义色不应全部漂白。共享 token 会影响设置/Git/其他表面，需决定全局主题还是工作台局部作用域。
- 验收：同尺寸截图的侧栏/主区/终端为三层中性灰黑；普通按钮不再大面积蓝色；次级字不再过暗。

### D02 根布局不是 V2 的左右独立纵向结构
- 当前：`plane/AgentPlane.tsx:136–194` 先创建跨两栏顶栏，再创建内容行。左头52px，右 TitleBar34px，外加整条1px下边线。`TitleBar.tsx:230` 消费 titleBarHeight 而非已定义 toolbarHeight46。
- 原型 `.app/.sidebar/.main/.sb-head/.toolbar`：左侧独立52px头部，右侧独立46px工具栏，主内容从 y=46 开始。
- 修改：重组根组件左右列，而不是只把34改46；保留系统窗口控制与拖拽能力。取消非原型的整窗硬分隔线。
- 验收：右主内容 y=46，不跟随左头52px整体下移。

### D03 顶栏组成基本未迁移
- 当前：`TitleBar.tsx:277–295` 普通标题；`AgentPlane.tsx:174–187` 尾部 Git 图/错误/HUD。无会话 chip、工具图标/caret、cwd、真实分支 chip、工作面板按钮。
- 原型：侧栏切换 → 会话chip → cwd → 弹性空位 → 分支chip → 条件搜索 → 固定面板钮。
- 目标：chip高28、全圆角、12px字；会话最大320、分支最大180；工具栏高46、左右内距12、gap8。会话chip点击打开新建工具弹窗；分支chip打开变更面板。
- 验收：所有上下文接真实会话/工作区，不硬编码示例分支；长标题不挤掉固定操作。

### D04 侧栏头的新建/搜索缺失，收起后无法鼠标恢复
- 当前：`Sidebar.tsx:65–90` 侧栏头只有收起按钮；隐藏后整个 Header 移除。`TitleBar.tsx:243–264` 只有 narrow 时有切换按钮，宽窗隐藏后没有鼠标恢复入口。
- 原型：侧栏头是新建＋与搜索，收起按钮常驻主工具栏；侧栏隐藏时搜索移到主工具栏。
- 另外：mac 隐藏侧栏后当前主标题仍仅左距12，未接替78px红绿灯让位。
- 修改：切换入口常驻、补两处条件搜索与全局新建；保留 mac 系统灯而不是画假灯。
- 验收：鼠标隐藏→恢复可连续操作；任何侧栏状态均有搜索入口；不碰撞系统灯。

### D05 右侧工作面板完全缺失，Git 图不能替代
- 当前：`Pane.tsx:42–85` 整页替换；`WorkspacePage.tsx:79–124` 为起始页/Git图tab；顶栏 Git 按钮调用 openGitGraph。
- 原型：终端旁辅助面板，默认关闭；变更/文件tab；M/A/D徽章、增删数、选中文件diff、文件预览；默认280，拖宽244–720且受可用空间约束；1100px以下覆盖右侧而非压缩终端。
- 修改：新增工程内面板宿主和真实数据接口，和终端主内容并存。不要把完整 GitGraphView 简单挤进280px侧栏。
- 验收：开关面板不改变活动会话，不销毁PTY；工作区切换刷新数据；非Git/空变更/加载失败有真实反馈；长代码横向滚动。
- 迁移决定：保留现有完整 Git 图的独立入口；是否取消工作区顶部tabs另行明确，不能擅删Git能力。

### D06 “临时会话”入口实际误归属
- 当前：`WorkspaceList.tsx:310–312` 传 openToolMenu('')，但 `ToolDialog.tsx:46` 使用 `find(...) ?? workspaces[0]`；下拉只列工作区，启动传 workspace?.id。
- 结果：存在工作区时，“新建临时会话”实际落入第一个工作区。
- 原型：临时入口含“未归属·临时会话”空值选项，空值传 null。
- 修改：显式区分“未归属”和“无效工作区”；检查 store 启动逻辑，避免再次fallback。
- 验收：已有两个工作区时，从会话区＋新建仍进入未归属区；从工作区＋新建继承该cwd；保留 preset.cwd 优先级。

### D07 全局新建快捷键未接入
- 当前：`keybindings.ts` 无新建动作/⌘N；`dialogKeyboard.ts` 仅暴露 openSearch。
- 原型：顶部＋、会话chip、⌘N共用新建弹窗，默认当前工作区。
- 修改：经现有键位/注入入口接入，遵守弹窗和终端快捷键仲裁，不直接在任意 keydown 中抢字符。
- 验收：⌘N打开正确目标弹窗；Esc返回；IME组合阶段不误触。

### D08 通知中心和侧栏footer未实现
- 当前：`Sidebar.tsx:144–207` 只有“齿轮 设置 Ctrl-,”；无铃铛、未读点、版本号。ErrorIndicator、ErrorDialog、Toast、terminal bell不等同于通知中心。
- 原型 `.sb-foot/.notif`：两个28px圆形图标按钮，右侧版本号；铃铛红点；320px浮层锚定铃铛上方8px；全部已读。
- 修改：补真实会话事件与未读模型，使用 anchored/deferred 浮层；不要复制原型假通知。
- 验收：未读事件出现红点、全部已读清除；浮层不被列表盖住、不跑出窗口。版本号读真实版本，不复制原型文案。

## P2：局部样式与交互

### D09 默认宽度没有真正生效
- `ui/tokens.ts` sidebarWidth264，但实际 `settings/schema.ts:103` catch(248)，Sidebar和Header订阅settings，因此新默认仍248。
- 改默认264并同步设置文案/恢复默认；尊重用户已保存自定义宽度，不强行覆盖。

### D10 工作区层级、当前态与操作形态不同
- `WorkspaceList.tsx:335`起：无当前工作区背景/5px标记点；常显数量和＋；hover直接显示关闭×；双击改名。
- 原型：当前组4%白底+5px点；更多…和＋；更多菜单内改名、显示全部/最近10个、移除。
- 当前组body只有column，无原型 `.ws-body` 的左13px margin、9px padding、1px淡竖线；folder12px而非14px；名称12px而非13px。列表外层缺原型左右8px留白。
- 修改：恢复分组线、缩进、当前态与菜单。不应保留“按下hover×立即移除全部会话”作为唯一管理入口；真实删除应有适当确认。
- 验收：工作区标题、时间标签、会话标题三级对齐；操作显隐不推动文本。

### D11 会话行还有旧样式，hover时文字宽度变化
- `ThreadRow.tsx:169–174` 行高28/圆角10已对齐，勿重做。
- 当前文字12px，原型13px；当前通用hover背景未配置到行容器；“… ”从0px占位变18px，且按钮为18px/3px圆角，原型22px圆形槽位常驻、只切可见性。
- 当前退出行另有“已退出”标签和bell；原型退出态仅文字变灰、状态由行首表达。
- 修改：固定菜单槽位、13px字、hover层级、核对状态冗余，不削掉真实通知能力。
- 验收：hover/选中/焦点前后标题宽度不跳动；非选中hover也有底色。

### D12 状态点视觉与语义不准确
- `ThreadRow.tsx:statusDot` 把所有未退出terminal都标running，pendingReply标need；done类型存在但分类器不会返回。
- 原型：idle默认无点，只有选中idle显示9px空心环；running/need为7px带同色halo与呼吸，done/error8px无halo。
- 当前idle全部显示6px空心环，非idle均7px带halo，无呼吸；颜色仍One Dark。
- 修改：先建立可证实的任务状态来源。进程活着不等于agent正在工作；pendingReply不等于等待权限确认。只有PTY存活信息时不能伪造完成/等待确认。
- 验收：切选中不覆盖任务状态；空闲Shell不会永远显示正在执行任务；未知状态保守表示；动画尊重减少动态设置。

### D13 时间分组和“展开其余”存在尾部空标签
- `WorkspaceList.tsx:192` 达到10条限制后仍 `return label`，会显示没有可见会话的昨天/本周/更早标题。
- 原型先取前10条，再为可见条目生成分组，末尾仅一个展开按钮。
- 临时会话原型是平铺，当前复用时间分组和10条限制；这是额外结构差异。
- 修改：先算可见列表再分组；工作区管理菜单补“只显示最近10个”。
- 验收：超过10条且跨多个时间组，没有孤立日期标签；展开数字准确；支持展开后收回。

### D14 临时会话行的管理回调漏接
- `TempSessionsSection` 调 TimeGroupedSessions 没有 onManage；最终 ThreadRow仍显示“…”，点击却 onManage?.() 无操作。
- 修改：和工作区会话一样传 dialog.openManageSession；后续统一菜单展示。
- 验收：未归属会话可从可见“… ”重命名/移除。

### D15 空态仍是旧版两套设计

- 验收：没有旧大卡、蓝色主操作或额外层层说明；窄窗胶囊可换行、路径不溢出。

### D16 工具弹窗尺寸和信息层级仍不同
