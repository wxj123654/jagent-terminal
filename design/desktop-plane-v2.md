## 保持的硬约束

- 终端仍是唯一内容区；工作面板是辅助停靠面板（Git/文件），不是第二内容区，不引入标签栏、分屏或应用级聊天 composer。
- 新会话继承工作区目录（cwd 链不变：`preset.cwd ?? workspace.path ?? process.cwd()`）。
- 点工作区行 = 切项目（激活其第一个/最近会话）；点箭头 = 仅展开收起，两操作分离。
- 原生落地仍走现有 PTY + `<terminal>`；本页 DOM 只是交互示意。

## 体验路径

1. 左侧「会话」区是无归属临时会话；「工作区」区按项目分组，组内按时间分组，状态点在行首。
2. 顶栏 `面板` 图标（或 Git chip）打开右侧工作面板：变更 tab 看文件列表 + 行内 diff，文件 tab 看预览；左缘可拖宽。
3. `＋`（侧栏顶 / 工作区行 / ⌘N）新建会话：弹窗内选目标工作区（显示 cwd）+ 工具（AI 编程 / 终端工具两组）。
4. 「工作区」区头 `＋` 添加工作区：名称 + 目录 + 浏览…（目录选择器），空值/相对路径/重复目录三态校验。
5. `⌘K` 跨工作区搜索会话；`⌘B` 收起侧栏；行 `…` 菜单重命名/移除。
6. 铃铛打开通知浮层（进行中/等待确认/已退出事件流），全部已读清除红点。

## 键盘与窗口

- 弹窗用 `<dialog>` + Esc；⌘K 搜索内 ↑↓ 导航、Enter 激活。
- 终端输入 Enter 提交（中文输入法组合阶段不提交）；回复标注「示例」。
- 760px 以下侧栏变抽屉 + scrim；尊重 reduced-motion。

## 已知简化（原型级）

- 会话草稿和示例回显在当前页面内按会话保留；刷新还原。工作面板宽度/状态、滚动位置不持久化。
- 终端内容、Git 变更、通知、分支均为示例数据。
- 无浅色主题（token 已按可扩展结构组织）。

## 本轮优化

- 输入区改为终端内左对齐输入行，不再使用悬浮胶囊；只在 AI 会话显示，明确标记不连接进程，空输入禁用发送。
- 工作面板开关固定保留，用选中态与 `aria-expanded` 表示状态；分支按钮打开变更面板。
- 1100px 以下面板覆盖在内容区右侧，不压缩终端；760px 以下侧栏为抽屉，隐藏区域不可聚焦，支持 Tab 循环和 Esc 返回。
- 侧栏收起或窄屏时，搜索入口移至主工具栏。长代码行横向滚动，不强行折行。
- 辅助文字对比度提高，移除侧栏布局动画，避免终端连续重排。
