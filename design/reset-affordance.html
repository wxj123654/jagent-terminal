行级「恢复默认」— 放置与形态设计

需求：设置里每一行都能恢复默认值。三个候选：A 行尾随控件（当前实现）、 B label 旁（Zed Settings Editor 真实做法）、C 行尾固定槽 + 状态分级（推荐）。 下方三个面板用同一组行（含宽窄不一的控件 + textarea 高行）演示差异；行内控件可操作， 改动后行变 modified，reset 出现，点击即恢复。

本页为设计对比原型，非产品 UI。

A · 行尾随控件

现状。reset 紧贴控件右侧 —— 注意不同控件宽度下 ↺ 的水平位置各不相同，且行在 modified / 默认间切换时按钮突然出现会推动整行布局。

B · label 旁 + 文字标注（Zed Settings Editor）

↺ 紧贴 label，后跟 muted 文字「— 已修改」。语义聚在左列，但位置随 label 长短漂移；文字常驻占宽；单文件场景（j-agent 只有 settings.json）文字信息量低。

C · 行尾固定槽 + 状态分级（推荐）

每行最右恒定 24px 槽。默认行：空槽，行 hover 时浮现 ghost ↺（tooltip「已是默认值」）——零常态噪音、功能可发现；modified 行：↺ 常显可 Tab（hover 抬底，tooltip 显示「当前值 → 默认值」）。↺ 永远在同一垂直线上。
