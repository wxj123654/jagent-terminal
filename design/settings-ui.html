Notifications · 通知

j-agent 只信任 BEL 与 OSC 标题两个信号；聚焦该 thread 即清除全部通知。没有「忙碌状态检测」——那是明确否决项。

只作用于 native TerminalView；行高与 cell 尺寸由 TerminalView 自管，不继承 UI 字体。终端背景使用独立 palette，不被父容器染色。
